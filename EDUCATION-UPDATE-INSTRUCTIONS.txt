EDUCATION ADMIN UPDATE

This update adds Education management to the existing admin dashboard and connects it to the Education view already present on the public website.

FILES INCLUDED
- public/admin.html
- public/admin.js
- functions/api/[[path]].js
- migrations/0001_create_education.sql

INSTALL
1. Back up your current GitHub repository first (or make a GitHub commit before replacing files).
2. Upload/replace the three matching code files in your EXISTING repository. Keep the same Cloudflare Pages project and existing D1 database binding.
3. In Cloudflare Dashboard, open Workers & Pages > D1 > your existing portfolio database > Console.
4. Open migrations/0001_create_education.sql from this ZIP, copy its complete contents, paste into the D1 Console, and run it ONCE.
5. Commit and push the file changes to the production branch used by your existing portfolio Pages project.
6. After deployment, sign in to /admin. Education will appear as a new dashboard tab.

The SQL migration only creates the education table and its index if they do not exist, and inserts the BOA Stage and Screen - Production Arts (Technical) starter entry if that ID is not already present. It does not drop or alter projects, skills, settings, admins, sessions, or other existing tables.

The public website's existing Skills/Education switch and education-list element are left unchanged. The public /api/education endpoint now returns visible entries from the new table.
